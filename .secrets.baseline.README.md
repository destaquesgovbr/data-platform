## O Que Está no Baseline

O arquivo `.secrets.baseline` contém hashes de "secrets" que são **falsos positivos legítimos**:

1. **Fixtures de teste** (`tests/`) - Credenciais mockadas para unit/integration tests
2. **Exemplos de documentação** (`docs/`) - Strings de exemplo em guias
3. **Referências a GitHub Secrets** (`.github/workflows/`) - Uso de `${{ secrets.X }}` (não são secrets reais)
4. **Scripts de setup** - Credenciais de desenvolvimento local (não são produção)

## Como Atualizar o Baseline

```bash
# Após adicionar/remover código que gera alertas legítimos:
poetry run detect-secrets scan --baseline .secrets.baseline \
  --exclude-files 'poetry\.lock' \
  --exclude-files '\.coverage' \
  --exclude-files 'htmlcov/.*' \
  --exclude-files '.*\.example$'

# Verificar mudanças:
git diff .secrets.baseline

# Commitar se as mudanças forem legítimas:
git add .secrets.baseline
git commit -m "chore: update secrets baseline"
```

## Tipos de Secrets no Baseline

- **Basic Auth Credentials**: Strings `postgresql://user:pass@host` em testes e docs  # pragma: allowlist secret
- **Secret Keyword**: API keys mockadas (`test-api-key`, `fake-key`, etc.)
- **Hex High Entropy String**: Hashes SHA para testes de consistência
- **Base64 High Entropy String**: Tokens codificados em workflows (GitHub Actions secrets refs)

## ⚠️ Importante

Se você encontrar um secret real (credencial de produção) durante a revisão:

1. **NÃO adicione ao baseline**
2. Rotacione a credencial imediatamente
3. Remova do código e use variáveis de ambiente
4. Reporte ao #security
